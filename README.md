# 🌙 Dark Mode Extension

یه اکستنشن کروم برای اضافه کردن دارک مود به صفحات روشن.

## ✨ ویژگی‌ها
- 🌓 Toggle سراسری
- 🎚️ تنظیم شدت تاریکی
- 🌡️ گرمی رنگ
- ⚪ لیست سفید برای سایت‌های خاص
- 🤖 تشخیص خودکار دارک مود نیتیو

## 🚀 نصب
1. این ریپو رو Clone یا دانلود کن
2. برو به `chrome://extensions`
3. **Developer mode** رو روشن کن
4. روی **Load unpacked** کلیک کن و پوشه پروژه رو انتخاب کن
